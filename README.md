# RustAim - C++ Aimbot

## Build Instructions

1. Установи Visual Studio 2022 с C++ девелопер тулзами.
2. Установи CMake.
3. Клонируй репозиторий:
   `git clone https://github.com/yourname/RustAim.git`
4. Собери проект:
   ```bash
   cmake -B build -DCMAKE_BUILD_TYPE=Release
   cmake --build build --config Release
